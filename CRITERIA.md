# Критерии поиска стажировок

Этот файл — основа для сайта и для автоматического поиска. Обновляем по мере уточнений.

## Кто ищет
- Студентка VILNIUS TECH (Вильнюс, Литва), учёба до 2028 года.
- Гражданство ЕС (Литва) — виза для работы/стажировки в ЕС не нужна.
- Языки: только английский → ищем вакансии, где английский рабочий язык или французский не обязателен.

## Формат
- Стажировки (internship / stage) **и** junior / entry-level позиции.
- Неоплачиваемые тоже подходят (возможен грант Erasmus+ traineeship).
- Только очно (удалёнка не подходит).
- Длительность не фильтруем — обсуждается с работодателем.

## География
1. **Франция — главный приоритет**, внутри Франции **Лион** в первую очередь, остальные города — на равных.
2. Другие страны тоже рассматриваем — **главный фокус на позиции, а не на стране**:
   - Нидерланды (хорошо, но рынок очень конкурентный)
   - Польша, Чехия (ок, но важно, чтобы рабочий язык был английский)
   - Остальные страны ЕС — если позиция сильная.

## Направления
Однозначно да:
- Медиа- и контент-стратегия
- Бренд-девелопмент, бренд-позиционирование
- Исследование аудитории, аналитика, market research
- Маркетинг (стратегический, не «просто вести соцсети»)

Скорее нет / низкий приоритет:
- Коммуникации и PR — под вопросом
- Культура и арт — нет опыта
- Креатив / арт-дирекшн — интересно, но нужно портфолио

Не подходит: рутинный SMM («просто постить контент») без стратегии и исследований.

## Компании
- Не микро-стартапы из нескольких человек (там стажёру просто перекидывают чужие задачи). Жёсткого порога по числу сотрудников нет.
- **Исключаем сферы:** табак, азартные игры / ставки, фаст-фэшн, оружие.
- **Бонус:** всё, что связано с международными студентами и международным образованием (студенческие сети вроде ESN, университеты, программы обмена, edtech для иностранных студентов).

## Источники
- **Erasmus Careers** (erasmuscareers.org, бывший ErasmusJobs от ESN) — вакансии видны без входа, роль «job seeker». ErasmusIntern — старый сайт, не используем.
  - ⚠️ Сейчас сайт заблокирован сетевыми настройками облачной среды — нужно будет разрешить доступ на шаге сбора вакансий.
- **LinkedIn** и **Indeed** — нужны. Оба запрещают автоматический сбор с их сайтов (скрапинг), открытого API нет. Подход: (1) находим их публичные вакансии через поисковик, (2) на сайте — готовые ссылки-поиски с нужными фильтрами, которые открываешь сама.
- **Welcome to the Jungle** — да.
- Чем больше разных источников, тем лучше — каждый новый проверяем: доступен ли автоматически и не запрещает ли это правилами.
- **Главный фильтр по всем источникам: вакансия на английском** (рабочий язык английский, французский не обязателен).

## Важные нюансы (Франция)
- Для stage во Франции нужен трёхсторонний договор **convention de stage** (студентка, компания, университет).
- Stage дольше 2 месяцев во Франции по закону **оплачивается** (gratification).
- Erasmus+ traineeship через VILNIUS TECH: компанию ищешь сама, заявка через mano.vilniustech.lt; список организаций можно запросить на internship@vilniustech.lt.
